# 인체 탐험 레이싱

몸속 기관을 달리며 우리 몸의 구조를 익히는 2D 코믹 카트 레이싱 게임.

## 플레이

브라우저에서 `index.html` 을 열면 바로 실행됩니다.

## 조작

| 키 | 동작 |
|---|---|
| W | 가속 |
| S | 브레이크 · 후진 |
| A / D | 좌우 |
| SPACE | 드리프트 → 부스터 (느려졌을 때 탈출용으로도 사용) |
| ENTER | 아이템 사용 |
| 마우스 휠 | 줌 |
| M | 전체 맵 |

## 맵

순환계 · 소화계 · 호흡계 · 신경계 · 배설계 5종.
각 코스는 그 계통의 실제 흐름(flow)을 따라 만들어졌고,
아이템과 장애물도 그 기관에 실제로 있는 물질입니다.
